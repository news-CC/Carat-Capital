# Demo clientele

Synthetic data for demonstrating the upload and the scrub gates. Regenerate with:

```bash
npm run demo:clientele
```

## Files

| File | What it is |
|---|---|
| `salon-malone-demo-clientele.xlsx` | 250 rows. Sheet `Clientele` holds the data, sheet `READ ME` states in plain words that it is synthetic. This is the file to upload. |
| `salon-malone-demo-clientele.csv` | The same 250 rows as CSV, for exercising the CSV path through the parser. |
| `upload-template.csv` | Headers only, plus two disposable example rows. The column set matches `UPLOAD_TEMPLATE_HEADERS` in `src/lib/parse-sheet.ts`. Give this to a salon. |

## This data is not real

Every row is generated by `scripts/generate-demo-clientele.mjs` from two word lists. There is no real
person in it.

**No number in these files can be dialled.** Every phone is `+1 (XXX) 555-01NN` — the range the North
American Numbering Plan reserves for fiction, the one film and television use precisely so that nobody
ever receives a call. The area codes are real; the lines behind them are not assigned and never will be.
Every email address is `@example.com`, which RFC 2606 reserves for documentation and which cannot
receive mail.

The generator is deterministic — a seeded PRNG, no `Math.random` — so re-running it reproduces the same
250 rows rather than churning the file.

## What the file is designed to prove

It is deliberately messy, because a clean file demonstrates nothing. Uploading it should drop 44 of 250
rows (17.6%) and tell you why for each one:

| Scrub outcome | Rows | What is wrong with them |
|---|---|---|
| `kept` | **206** | Consent granted, phone valid, unique. Queued as `pending`. |
| `dropped_no_consent` | 34 | Consent recorded as `FALSE`, `false`, `no`, `No`, `N`, `0`, `pending`, `unknown`, or left blank. |
| `dropped_invalid_phone` | 7 | Too short, area code starting `0` or `1`, all zeroes, or free text like `no phone on file`. |
| `dropped_missing_phone` | 1 | Phone cell empty. |
| `dropped_duplicate` | 2 | Same number as an earlier row — one guest recorded twice with and without a middle initial, and two people sharing a household number. |
| `dropped_suppressed` | 0 | Depends on your `suppression` table. Add a number to it and re-upload to watch this one move. |

The rows that survive also exercise the parser on purpose: consent arrives as `TRUE`, `true`, `yes`,
`Yes`, `Y`, `y`, `1`, `t`, `granted`, `opted_in`, `opt_in` and `consented`; phones arrive in seven
presentation formats; `last_visit` arrives in six date formats plus blanks; `lifetime_value` arrives as
`$1,234.50`, `$980`, `1234.5`, `2,100`, `0` and blank.

## Running the demo

1. `/admin/clients` → **New client**. Name it *Demo Salon*, set the timezone to yours, write a real
   offer (it is what Malone says out loud), set the average ticket.
2. Open the client → **Upload** → pick `salon-malone-demo-clientele.xlsx`.
3. Confirm the header mapping, then read the **dry-run scrub preview**. Those are the numbers in the
   table above. Nothing has been written yet.
4. Confirm. 206 contacts land as `pending`; the 44 dropped rows are counted but never inserted.
5. **Leave this campaign paused.** See the warning below.

### Getting an actual call to your own phone

Make a *second* client and give it a one-row list containing your own mobile, `consent` set to `TRUE`.
Start that campaign inside its calling window and Malone will call you. Book a slot out loud, hang up,
and within a minute or two the booking alert should arrive at that client's `contact_email` and the row
should appear under Bookings.

You are the consenting party, so this is the one case where putting a real number in a list is fine.

### Do not start a campaign on the 250-row demo list

Nothing in the code refuses to dial a fiction-range number — `isFictionalPhone()` exists in
`src/lib/phone.ts` but no gate calls it. Starting the demo campaign would therefore hand 206 unroutable
numbers to Vapi, which bills the attempts and returns 206 failed calls. It costs money and teaches you
nothing.

Upload the demo file to watch the scrub. Use a separate one-row client to hear Malone.

## Do not swap this for real data

Do not replace these rows with a real client list to "test with real data". The whole point of the
555-01NN range is that a mistake cannot reach a stranger. Upload a real list only when it carries real,
documented consent — and read the compliance section of the root `README.md` first.
